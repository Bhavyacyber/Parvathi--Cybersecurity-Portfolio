## Featured work

My current direction is application and product security. These projects show the practical foundation I’m building on, from network and phishing analysis to web and API assessment.

### Network reconnaissance and phishing investigation

[Read the assessment report](SELF_PORTFOLIO_PROJECTS/project_footprinting_reconnaissance_networkscanning.pdf) · [Phishing email detection guide](SELF_PORTFOLIO_PROJECTS/Phishing_Email_Detection_Guide.pdf)

Used Nmap, Recon-ng, OpenVAS, VirusTotal, and MXToolbox to map 12 open services and 3 exposed ports. Reviewed more than 10 phishing emails for spoofed domains, SPF/DKIM failures, and malicious redirects; documented indicators of compromise and recommended mail gateway rules.

### OWASP Juice Shop vulnerability assessment

[Read the assessment report](SELF_PORTFOLIO_PROJECTS/OWASP_Juice_Shop_Vulnerability_Testing_Report_Parvathi.pdf)

Assessed the OWASP Juice Shop training application using Burp Suite and Kali Linux. Reported five findings, including authentication bypass, IDOR, sensitive endpoint exposure, and XSS issues, with OWASP Top 10 mapping and impact analysis.

### API and web application security assessment

[Read the Wallarm API assessment report](SELF_PORTFOLIO_PROJECTS/Wallarm_API_VAPT_Report.pdf)

Performed a black-box REST API assessment with Burp Suite, Postman, and OWASP ZAP. Documented five findings, including BOLA and authentication weaknesses, and mapped attack paths to potential SIEM detections.
